## B.2 数据存储与数据丢失风险 —— **实际发生,是本项目最主要的工程约束**

### 风险描述

本研究使用 LeBel et al. (2023) 的公开自然语言听觉 fMRI 数据集(OpenNeuro `ds003020`)。
该数据集体积远超一般学生项目的预期:

| 项目 | 实测数值 |
|---|---|
| 单个故事的预处理 BOLD 文件(`.hf5`) | 约 180–300 MB |
| 单名被试的故事数 | 84 个 |
| **单名被试的 BOLD 数据总量** | **约 23 GB** |
| 本研究分析的被试数 | 3 名(UTS01 / UTS02 / UTS03) |
| **三被试完整数据估算** | **约 69 GB** |
| 另需:模型特征缓存、Ridge 结果 | 结果目录实测 3.2 GB |

风险在于:**本地工作站无法同时容纳三名被试的完整数据**,且数据一旦丢失需要从 OpenNeuro
重新下载(数十 GB,耗时以小时计)。

### 实际发生的情况

本机(WSL2 环境)最终只实体化了 **UTS03 一名被试的数据(23 GB)**;UTS01 与 UTS02 的
`.hf5` 文件在本地**仅以 datalad/git-annex 符号链接占位存在,内容未下载**——实测确认这两名
被试的文件解引用失败,真实数据只存在于远程计算服务器上。

### 已实施的缓解措施

1. **采用 datalad / git-annex 按需获取**:数据集以符号链接方式管理,只对当前真正需要的被试
   执行 `datalad get`,不做全量下载。这使本地磁盘占用从约 69 GB 降到 23 GB。
2. **计算与存储分离**:所有重计算(模型特征提取、Ridge 拟合)在远程 GPU 服务器上进行,大体积
   中间产物(特征缓存 `cache/features/`)只存在于服务器,不回传本机。
3. **只回传小体积衍生结果**:本机只保留逐故事统计结果(JSON)、图表与冻结文件。统计分析
   (M5)与出图(M6)因此可以完全在本地离线完成,不依赖服务器在线。
4. **原始数据只读**:分析流程从不写回 `data/` 目录;所有产物写入独立的 `results/` 与
   `figures/`,原始数据不存在被脚本破坏的路径。
5. **代码与结果分离备份**:代码通过 Git 推送至远程仓库(GitHub)保存;大体积数据不入版本库
   (`results/*` 已列入 `.gitignore`),避免仓库膨胀导致推送失败。
6. **数据可重新获取**:数据集为公开数据集(DOI `10.18112/openneuro.ds003020.v3.1.1`),
   最坏情况下可从 OpenNeuro 重新下载,不存在**永久性**丢失风险。

### 残余风险

**中**。服务器上的特征缓存若随实例释放而丢失,需重跑 GPU 提取(约 1 小时)。已通过"结果 JSON
及时回传本机"将不可恢复的损失限制在可重算范围内。

## B.3 计算资源与长时间运行风险 —— **实际发生**

### 风险描述

本研究需在 GPU 上完成:4 个语言模型 × 3 种上下文长度 × 84 个故事的特征提取,以及
每名被试 108 次 Ridge 交叉验证拟合。风险包括:算力不足、任务长时间运行中断、
云服务器实例不可用、计费超支。

### 实际发生的情况(均已解决,如实记录)

| 事件 | 现象 | 处理方式 |
|---|---|---|
| **内存耗尽卡死** | UTS02/UTS03 的 Ridge 拟合阶段系统内存占用达 95%,GPU 空转、20 分钟无进展 | 定位到每个计算单元重复加载了完整 BOLD 矩阵(约 9.4 万体素)仅用于推导评分掩码。改为直接从元数据计算掩码、不加载 BOLD,并显式释放内存后解决 |
| **云实例停机 / 连接失败** | 服务器 SSH 出现 `Connection refused`,实例已停止(撰写本文档期间再次发生) | 计算任务全部设计为**可断点续跑**;结果按单元落盘,重连后跳过已完成单元 |
| **实例地址变动** | AutoDL 实例的 SSH 主机名与端口在重建实例后会改变 | 不将连接信息硬编码进脚本;代码同步统一走 Git 远程仓库中转,不依赖固定 IP |
| **网络受限** | 服务器无法直连 HuggingFace 下载模型权重 | 改用国内镜像站获取权重 |
| **环境变量异常** | `OMP_NUM_THREADS` 取值非法导致 libgomp 报错 | 在启动命令中显式设置合法值 |

### 已实施的缓解措施

1. **断点续跑设计**:计算矩阵拆分为独立单元(模型 × 上下文长度 × 层 × 折),每个单元独立
   计算、独立落盘,支持 `--skip-existing` 跳过已完成部分。**任何时刻中断都不会丢失已完成的工作。**
2. **进程隔离**:4 个模型拆分为 4 个独立入口脚本,可分别启动、互不阻塞;单个模型失败不影响其余。
3. **明确的算力安全纪律**:项目约定**未经明确确认不启动重计算任务**(GPU 推理 / Ridge 拟合),
   避免误触发导致的计费损失与资源浪费。
4. **轻重分离**:统计推断(Bootstrap)与绘图为纯 CPU 任务,在本地完成,不占用付费 GPU 时长。
5. **计算前先做小规模竖切验证**:在展开完整矩阵前,先以单模型 / 单上下文长度跑通端到端流程
   (对应里程碑 M3),避免在全量任务上才发现流程缺陷、造成大规模返工。

### 残余风险

**中**。云实例可用性不受本人控制;已通过断点续跑与结果及时回传,把单次中断的代价限制在
"重跑最后一个未完成单元"。

## B.4 预训练模型与第三方数据的许可风险

### 涉及的第三方资源

| 资源 | 来源 | 用途 |
|---|---|---|
| 数据集 `ds003020` | OpenNeuro,LeBel et al. (2023) | fMRI 响应与刺激文本 |
| Pythia-160M | EleutherAI(HuggingFace) | Transformer 架构代表 |
| Mamba-130M | state-spaces(HuggingFace) | 状态空间模型代表 |
| RWKV-4-169M-Pile | RWKV(HuggingFace) | 线性注意力 / RNN 架构代表 |
| AWD-LSTM (WT103) | fastai | 历史参照模型 |
| 基础分析代码 | HuthLab `deep-fMRI-dataset` | MIT 许可(仓库内含 LICENSE) |

### 缓解措施

1. **数据集许可已核实**:`dataset_description.json` 中 `"License": "CC0"`,属公有领域声明,
   允许学术再利用。已按数据集要求在论文中引用 LeBel et al. (2023), *Scientific Data* 10, 555。
2. **仅使用公开发布的预训练权重**,不进行再分发——论文与代码仓库中不包含任何模型权重文件,
   只记录模型标识符与版本号,读者需自行从原始来源获取。
3. **模型版本可追溯**:记录了每个模型实际使用的 HuggingFace 仓库 ID 与 commit SHA,
   确保引用的是确定的权重版本。
4. **基础代码遵循 MIT 许可**,保留原始版权声明。

> **提交前需确认事项**:各预训练模型的具体许可条款(通常为 Apache-2.0)建议在定稿前
> 到各自 HuggingFace 页面再核对一次并在论文中标注,本文档不代替该核对。

### 残余等级:**低**

## B.5 数据隐私与合规风险

### 风险描述

研究对象为人类被试的脑影像数据,涉及个人敏感信息。

### 缓解措施

1. **使用已公开发布、已去标识化的数据集**,本人**不参与任何原始数据采集**,不接触可识别
   个人身份的信息。原始伦理审查由数据发布方(University of Texas at Austin)完成并已公开发表。
2. **数据集内不含直接标识符**:被试以编号形式表示(如 `sub-UTS01`);`participants.tsv`
   仅含年龄与性别等基本人口学变量,无姓名、联系方式或影像面部信息。
3. **不进行个体身份推断**:本研究的分析单位为群体层面的模型比较,不涉及从脑数据反推
   个人特征或身份的任何尝试。
4. **不再分发原始数据**:论文与代码仓库不包含任何 BOLD 原始数据;读者需自行从 OpenNeuro
   按其许可获取。
5. **逐被试独立报告**:结果按被试分别呈现,但仅以匿名编号出现,不附带任何可关联到真实个体的信息。

### 残余等级:**低**

## B.6 结果可重复性风险

### 风险描述

分析流程涉及上千个分散在不同时间、不同机器上完成的计算单元。若分析设定在过程中发生
漂移,或随机性未受控,结果将无法复现,亦无法合法地相互比较。

### 已实施的缓解措施

1. **分析设定事前冻结**:在任何模型计算开始之前,将统一词索引、交叉验证折划分、ROI 定义规则、
   全部分析参数一次性写入 `frozen/` 目录,后续所有步骤只读不改。
2. **随机种子固定并记录**:Bootstrap 种子(20260701)、补充实验的扰动种子(20260724)均为
   固定值并写入冻结文件与结果元数据。
3. **代码版本随结果落盘**:每个计算单元的结果文件中记录生成时的 Git commit hash,
   可精确回溯到产出该数字的代码版本。
4. **统计口径事前分层**:确认性 / 探索性 / 诊断性三类结论的界限在分析开始前即已划定,
   避免事后择优报告(见论文正文方法部分)。
5. **管线外部锚定**:用公开的 English1000 词嵌入特征跑完全相同的分析管线,与已发表的
   参考结果比对,受限相关达到 0.995,验证管线实现本身无误。
6. **关键不变量写成断言**:如"特征矩阵、BOLD 矩阵、时间轴三者行数必须相等",
   任何时间轴错位都会当场报错而非产生看似合理的错误结果。

### 部分发生的情况(如实披露)

补充实验中有两项诊断指标的**实现时间晚于主要结果的产出**(定义取自事前冻结的设计文档、
未事后调参,但时序需要说明);此外该补充实验中有两项跨条件对比属**事后新增**,
已在结果记录中明确标注。相关限制已在论文中如实披露,不作为确认性证据使用。

### 残余等级:**低**

## B.7 工作站使用、用电与长时间屏幕作业的健康安全风险

### 风险描述

论文写作与数据分析涉及长时间使用计算机,存在视疲劳、颈肩劳损、重复性劳损(RSI)风险;
本地工作站长时间运行涉及一般用电安全。

### 缓解措施

1. **计算负载外置**:所有长时间高负载计算在远程服务器上运行,本地工作站不需要长时间满载
   运转,显著降低本地设备发热与持续用电风险。
2. **任务异步化**:GPU 任务提交后无需在屏幕前值守,支持断点续跑,不存在"必须整夜盯着屏幕"
   的作业模式。
3. **常规工效学措施**:遵循学校建议的用眼与休息节律(如每小时短暂休息、20-20-20 用眼法则),
   调整显示器高度与座椅以保持中性坐姿。
4. **用电安全**:使用符合规格的电源设备,不私自改装;设备置于通风处,不覆盖散热口;
   离开时不使高负载设备无人值守长时间运行。
5. **无实验室 / 无被试接触**:本研究为纯二次数据分析,**不涉及实验室作业、化学品、
   仪器操作或与人类被试的直接接触**,因此不涉及相应的实验室安全风险。

### 残余等级:**低**

## B.8 供论文正文引用的一段小结

> 本研究为基于公开数据集的二次分析,不涉及新的人类被试招募或实验室作业。主要风险集中于
> 工程与数据管理层面:数据集体积庞大(单名被试约 23 GB,三名被试合计约 69 GB),超出本地
> 工作站的存储能力,因此采用按需获取策略并将计算与存储分离,重计算在远程 GPU 服务器完成、
> 仅回传小体积统计结果。远程实例在项目期间曾出现停机与内存耗尽导致的任务中断,已通过
> 单元级断点续跑设计将中断代价限制在可重算范围内。所用数据集为 CC0 许可的去标识化公开数据,
> 不涉及个人身份信息且不作再分发。为保证可重复性,全部分析设定、随机种子与代码版本
> 在计算开始前冻结并随结果落盘。
